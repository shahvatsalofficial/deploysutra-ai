# Support

- **Questions and ideas:** GitHub Issues on https://github.com/shahvatsalofficial/deploysutra-ai
- **Bugs:** open an issue with the command, `deploysutra --version`, your Node version and OS, and a **sanitized** minimal manifest. Attach `deploysutra audit --out audit-out` output if you can.
- **A rule fires wrongly (or does not fire):** attach the smallest manifest and the rule ID. Good samples become corpus cases in `packages/core/corpus.mjs`.
- **Security:** see SECURITY.md. Never paste real credentials, kubeconfigs or plan state into an issue.

This is a volunteer-maintained project; there is no commercial support or SLA.
