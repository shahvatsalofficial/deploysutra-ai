What was independently reviewed

Nothing. The audit is the tool testing itself, the corpus is written by the author, and no third party has reviewed the code. These documents say so on purpose. If you need independent assurance, review the source (about 2,000 lines, no dependencies) or commission a review; the audit report and corpus give a reviewer a head start.

Not run

Live cluster dry-run, MCP Inspector or third-party MCP clients, native skill activation in each IDE, independent benchmark, signed releases, other operating systems in the recorded local run (CI covers them).

Reproduce everything

git clone https://github.com/shahvatsalofficial/deploysutra-ai && cd deploysutra-ai
npm test
npx deploysutra-ai audit --out audit-out
npx deploysutra-ai verify --report audit-out/audit-report.json

Reading the evidence critically

A pass means "the tool behaved as designed on these inputs". It does not mean "your deployment is safe". Use it as one input to a human decision.
